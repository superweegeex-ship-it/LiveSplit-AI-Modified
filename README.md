Largely modified version of the original Livesplit by wooferzfg.
Used AI entirely to write the code, just used my own ideas to steer it in the right direction for backend choices and other things.

For any information related to Livesplit not present here, see the original [Livesplit](https://github.com/LiveSplit) github page.

List of features: (still updating)
- Dark mode/system mode
- Resizable windows everywhere
- Resizable font box elements
- 3 color gradient on detailed timer
- Animated image and video playback as background
- Options for various types of blur as the background
- Hardware decoding options
- Debug statistics menu bound to hotkey
- Resizable seperators
- Offsets to when video starts, including syncing video playback to starting the timer or not having that
- Video zoom, panning, etc
- Potentially more unlisted, more to come
